# v0.1.0 release commands

Status: **HISTORICAL v0.1.0 RUNBOOK — RELEASE COMPLETED**

v0.1.0 was published on 2026-07-29. Do not rerun these mutation commands, republish version 0.1.0, or move
its tag. For a future release, copy this runbook to a new version-specific document, revalidate every
command, and obtain fresh owner approval.

The commands below preserve the reviewed release sequence as historical evidence. Every command that changes
public state is marked **PUBLIC/DESTRUCTIVE**. Never force-push, reuse a published version, replace an
existing tag, or print a credential.

This initial no-CI release used interactive write-protection 2FA and does not claim npm provenance.
Repository visibility changed before package publication so source and security reporting were public.

## 1. Final synchronization

```sh
git status --short --branch
git fetch origin
git rev-parse HEAD
git rev-parse origin/main
git tag --list v0.1.0
gh release view v0.1.0 --repo SUDARSHANCHAUDHARI/TemporalThread
```

At release time, this required a clean `main`, identical local/remote commits, and no existing `v0.1.0` tag
or release. Those absence checks are intentionally false now because the immutable release exists.

## 15. Rollback or deprecation

**PUBLIC/DESTRUCTIVE — incident approval required.** Stop further dependent publishes first. Prefer a
fix-forward release and deprecation warning:

```sh
npm deprecate temporalthread@0.1.0 "Known issue; use <fixed-version>"
npm deprecate @sudarshanchaudhari/temporalthread-<affected-package>@0.1.0 "Known issue; use <fixed-version>"
```

Do not delete/repoint the Git tag. Do not unpublish by default. If accidental secret or unsafe content was
published, follow the incident plan and current npm unpublish policy, revoke credentials, rotate affected
secrets, and publish a new immutable version.
