## Decision rationale

This is not yet a CONDITIONAL GO because the distributable dependency graph fails a security gate and the
required npm scope cannot currently be administered with the available account credential. The decision can
move to CONDITIONAL GO only after a stable dependency resolution produces a green three-platform release dry
run and scope/2FA authority is established. It can move to GO only after real-host certification and every
public-action approval has recorded evidence.

## Exact next human action

Do not publish the existing tarballs. First track or request a stable MCP TypeScript SDK release that permits
`@hono/node-server@2.0.10` or newer, update TemporalThread, and rerun release dry run `29932142666`'s matrix.
Only after that gate is green should the maintainer verify npm scope/2FA authority and run the text-only live
Codex procedure in `docs/LIVE-CODEX-CERTIFICATION.md`.
