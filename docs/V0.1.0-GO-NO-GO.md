## Decision rationale

The current exact commit cannot move to CONDITIONAL GO until the normal three-platform workflow is observed
passing after Phases 4.2C–4.2E. Even after that, the distributable dependency graph and npm authority blockers
would keep v0.1.0 at NO-GO. A stable dependency resolution must produce clean npm and pnpm packed consumers
and a green release dry run before fresh artifacts, checksums, or an SBOM are generated.

Real Codex host certification is deferred by owner decision. The new host-neutral MCP path strengthens the core
protocol claim but does not certify Codex UI, trust, hooks, or model behavior.

readiness, and explicit approval for every public-state mutation. Do not reveal tokens or recovery codes.
