## Decision rationale

This is not yet a CONDITIONAL GO because the distributable dependency graph fails a security gate and the
required npm scope cannot currently be administered with the available authority. The decision can move to
CONDITIONAL GO only after a stable dependency resolution produces a green three-platform release dry run and
scope/2FA/recovery authority is established. It can move to GO only after fresh artifacts, checksums, SBOM,
and every public-action approval have recorded evidence.

Real Codex host certification is deferred by owner decision. A future live certification may improve support
confidence, but v0.1.0 must not advertise certified Codex CLI, desktop, trust, UI, hook-delivery, or model
behavior until that test is genuinely completed.

## Exact next human action

Do not publish the existing tarballs. First track or request a stable MCP TypeScript SDK release that permits
a patched `@hono/node-server` line; upstream issue `modelcontextprotocol/typescript-sdk#2531` tracks the blocked
range. Update TemporalThread only after a stable release, then rerun the dual-manager packed-consumer and
three-platform release-dry-run matrix.

While waiting, establish the independent npm prerequisites: confirm or create the `temporalthread`
organization/scope through the npm website, verify owner/admin authority, confirm write-protection 2FA and
recovery readiness privately, and do not reveal tokens or recovery codes. None of those actions authorizes
publication while the dependency gate remains blocked.
