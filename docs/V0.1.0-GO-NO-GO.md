## Decision rationale

Focused review and the required local validation passed in merged pull request `#3`. This branch adds fresh
frozen-install, lint, typecheck, 29-file/168-test, build, production-audit, and secure packed-consumer
evidence. The dependency graph is cleared, but npm authority and owner approval remain blocked, so v0.1.0
remains at NO-GO.

The stable supported dependency resolution now produces clean npm and pnpm packed consumers. This does not
authorize fresh release artifacts, checksums, an SBOM, publication, or public-state changes. CI and GitHub
Actions are intentionally absent; local validation is the repository policy.

Real Codex host certification is deferred by owner decision. The new host-neutral MCP path strengthens the core
protocol claim but does not certify Codex UI, trust, hooks, or model behavior.

## Exact next action

The dependency blocker is cleared. The owner must personally verify npm scope authority, write-protection
2FA, and recovery readiness, then explicitly authorize any release artifact generation, publication, or
public-state mutation.

The independent human prerequisites remain: npm scope owner/admin authority, write-protection 2FA, recovery
readiness, and explicit approval for every public-state mutation. Do not reveal tokens or recovery codes.
