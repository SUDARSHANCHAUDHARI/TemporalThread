## Decision rationale

The owner accepted the documented v0.1.0 evidence boundaries and authorized the initial release. The
published package graph, tag, assets, and repository state now confirm that the release was executed.

The release does not supply current exact-release Linux/Windows evidence, real Codex host certification,
npm provenance, cross-platform reproducibility, or sustained production-use evidence. Those omissions do
not undo the v0.1.0 publication, but they prevent a production-ready claim.

## Next decision

Treat v0.1.0 as immutable. Any fix must use a new version. Any new release, CI workflow, repository-setting
change, live-host certification run, or announcement requires a separately scoped owner decision.
