## Decision rationale

This is not yet a CONDITIONAL GO because an external distribution capability—not only a manual test—is
missing: the required npm scope cannot currently be administered with the available account credential. The
decision can move to CONDITIONAL GO after scope/2FA authority and the final three-platform dry run pass; it
can move to GO only after real-host certification and every public-action approval has recorded evidence.

## Exact next human action

The maintainer should first establish or verify ownership of the `temporalthread` npm organization and confirm
2FA/recovery access. Do not publish anything. Then run the temporary packed-candidate Codex procedure in
`docs/LIVE-CODEX-CERTIFICATION.md` and return the text-only results for gate review.
