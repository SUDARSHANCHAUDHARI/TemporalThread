# TemporalThread

Retrieve temporal context at session start, after meaningful inactivity, and for temporal references. Anchor relative language to the original message time and timezone. Record explicit follow-up commitments, preserve vague ranges, and update status only from evidence. Use manual `record_interaction` calls when the host has no automatic capture event. Keep temporal details relevant and privacy-aware.
